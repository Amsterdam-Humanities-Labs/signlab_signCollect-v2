# Architecture documentation

`signcollect-architecture.html` is the source — a self-contained page (no build step, diagrams are generated by inline JS as SVG). Edit it directly, then regenerate the PDF with:

```bash
google-chrome --headless=new --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=signcollect-architecture.pdf signcollect-architecture.html
```

The PDF is A4 landscape, 12 pages: overview, menu map, frontend modules, endpoint reference, database map, and sequence diagrams for the main workflows (list/filter, add, edit + Signbank auto-sync, video recording, Signbank lifecycle, auth).
